# Wireless Battery Monitor 1.1.1

Versão corretiva para Windows x64 baseada na v1.1.0.

- O Delux M800 Pro PAW3395 interpreta separadamente o percentual de 1 a 100 e a indicação de carregamento do receptor. Valores fora da faixa indicam leitura indisponível.
- O monitor respeita a desativação da inicialização automática feita pelo Gerenciador de Tarefas. É possível reabilitá-la explicitamente nas preferências do aplicativo.
- A documentação descreve o relatório usado na consulta do GameSir Cyclone 2.

No teste físico da versão 1.1.1, o receptor Delux informou 82% em bateria, 100% durante a carga e 89% após a retirada do cabo. O valor durante a carga é o percentual informado pelo receptor.

Os pacotes para Windows x64 são `WirelessBattery-1.1.1.exe` e `WirelessBattery-1.1.1-portable-win-x64.zip`. Compare o SHA-256 do arquivo baixado com `SHA256SUMS.txt`. Consulte o README para os dispositivos compatíveis, os créditos e as licenças.
